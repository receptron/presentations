## 引っかかったところ

### テイクは黙って凍る（この 2 本で最大の時間を溶かした）

**`page.screencast` は CDP が新しいフレームを寄越さなくなると、最後に受け取ったフレームを書き続ける。**
結果できあがるのは、**尺もフレーム数も正しく、中身だけが途中で止まっている** webm。
最初のセッションで撮った 4 テイクは全部これで、Cancel を押した瞬間も、日本語サイドバーのスクロールも、
「撮ったつもり」で 1 フレームも残っていなかった。エラーは出ない。

- **判定は `verify-takes.sh` に任せる。** テイクを止めた瞬間に撮る `<name>-final.png` が
  「ページが最後にどうなったか」の正解なので、動画の最終フレームと PSNR で突き合わせる。
  30dB 未満なら凍っている
- **最終フレームを `-sseof` で取ってはいけない。** これらの webm は index を持たないので
  `-sseof` は**先頭近くのフレーム**を返す。最初これで判定して、無事なテイクまで
  全部「凍っている」と判定し（しかも毎回同じ PSNR が出るので env 由来だと誤診し）、
  正常なテイクを 4 回撮り直した。正規化した CFR mp4 に対して絶対時刻でシークする
- 原因の切り分けとして試して**効かなかったもの**: `--disable-features=CalculateNativeWinOcclusion`
  （macOS の occlusion 検出を切る）、`caffeinate -dimsu`、`page.bringToFront()`、
  `el.click()` を `page.mouse.click()` に変える。**headless も不可** — `deviceScaleFactor: 2` を
  渡しても screencast は 1440x900 で出てきて、rig が前提にしている 2x が失われる
- 確実に再現するのは**確認ダイアログ（`fixed inset-0` のオーバーレイ）が出ている間**で、
  ここは 3 回撮って 3 回とも凍った。なので `02-it-asks` の「Cancel を押した後」は
  **撮影ではなく `cancel-final.png`（実スクリーンショット）** で作っている。
  前後で画角が同じなので、カットがそのまま「ダイアログが消えた」に見える。
  焦点リングがボタンに戻っているところまで、その静止画が持っている
- **1 テイク 1 ビートで撮る。** 長回しは凍った瞬間に以降が全部無駄になる

### 画角の外で押していた

サイドバーを一番上に戻してから `Notification sounds` を押していたが、その行は 1800px のフレームの
**1384px 目**にあり、他の 2 場面（ペインの見出しと言語ピッカーは modal の**上**に出る）を含む
2.5:1 の帯には入らない。**押す行が画角に入るところまでサイドバーをスクロールさせてから押す**
（`reshoot-sidebar.mjs` の `NOTIFICATIONS_SCROLL`）。押す前に行の座標をログに出しておくと、
リングの `drawbox` 座標を静止画から目測せずに済む。

### 九つのグループは、ページのスクロールだけでは映らない

nav は 920px の中身を 642px の窓で見せているので、下の 3 グループはページをスクロールして初めて出る。
一方こちらの画角（modal の上の帯）は**その窓のいちばん動かないところ**を見ているので、
固定カメラだと見出しが 6 つ流れるだけで、ナレーションの「九つ」を絵が裏切る。
**ページのスクロールに合わせてカメラを下にパンさせる**と 9 グループ全部が画角を通る。
これは `camera-move.mjs` の仕事ではない（あれは矩形に向かって寄る）。倍率を変えずに動かしたいので、
素の `crop` の y に式を書く（`build-clips.sh` の `$PAN`）。

### `enable=` はフィルタグラフの時計で数える

`-ss` を `-i` の**後ろ**に置いた場合、シーク自体は効くが**フィルタグラフには元のタイムスタンプが流れる**。
クリップ先頭からの秒数で `drawbox ... :enable='between(t,0.75,1.48)'` と書くと、その窓は一度も来ず、
**リングは黙って描かれない**（エラーは出ない）。`trim=start=…:end=…,setpts=PTS-STARTPTS` で
グラフの中で切って振り直す。`-t` も同じ理由で `tpad` と噛み合わない
（出力側の尺制限なので、`tpad` で伸ばしたぶんがそのまま切られる）。

### リングの色は、そのボタンに元から付いている色で決める

確認ダイアログは既定のフォーカスが **Cancel** にあり、ブラウザが白いリングを描く。
Start は青い塗りのボタン。ここに前例どおりの藍色（`0x818cf8`）のリングを Start へ描くと
**青に沈んで見えず、フレームは「Cancel が選ばれた」ように読める**。Start には琥珀（`0xfbbf24`）を使う。
逆に **Cancel を押す場面ではリングを描かない** — ブラウザのフォーカスリングが既に指しているので、
その上に重ねても情報が増えない。

### クリップは音声より長く、しかも「寄り切る」まで含めて長く

`duration` を書かないので尺はナレーションが決める。**クリップが音声より長い**だけでは足りず、
**カメラが動き終わるのが音声より前**である必要がある。beat 3 は最初、寄りが始まる前に
ナレーションが終わっていて、約束した「ターミナルが開く」を寄って見せる前に動画が終わっていた。
日本語は英語より 1.2 秒ほど長く出るので、余裕はそちら基準で取る（実測 6.6 → 7.9 秒）。

## 公開前に判断が要る 1 点

`skill-asks-first` の最後の場面は、起動したセルを寄って見せるので **Claude Code の起動バナーが読める**。
そこに出るのは `~/mulmoclaude`（撮影ホストの workspace ディレクトリ名）と `Claude Max`（契約プラン）。
個人を特定する情報ではないが、ディレクトリ構成とプランは分かる。**気になるなら**、この場面の
寄りの終点を `--target` でセルのヘッダ側に上げるか、`build-clips.sh` の `--push` を浅くする。
それ以外の場面に写るパスは `/tmp/mt-demo/acme-*` と demo config のプリセットだけで、設計上見せてよい。
