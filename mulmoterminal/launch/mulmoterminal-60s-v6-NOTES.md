v4 / v5 の JSON は同じ絵では再レンダリングできない（完成品は `output/` と Downloads にある）。

## 何を直したか

| 指摘 | 対応 |
|---|---|
| 最初の 6 秒が不要 | 冒頭を切り、**チャイム＋amber の 2.3 秒前**から始まる |
| ピコンと鳴って amber になってから寄る | 寄りの開始を amber の**後ろ**へ（`hold 2.6` = 点灯の 0.3 秒後に押し込み開始）|
| 12〜15 秒は早送りでよい | 回答後の間を 3 倍速で詰め、すぐ "This is a terminal…" に入る |
| 16〜30 秒は上のセルが止まって見える | 撮り直し。回答後の打鍵先を**上段 web / 右上 auth**（＋mobile）に変更 |
| diff は 1 行では物足りない | タスクを「17 行の docs/error-format.md を書いてコミット」に変更 |
| diff は「6 セル → 拡大 → 確認」の映像がよい | 撮り直し。**6 セル → 拡大（左にロスター）→ ヘッダの diff チップ → パネル**の一連を 1 テイクで |
| チップを囲ってから寄る | チップのリングは**クリック前**（3.6〜4.8 秒）に出し、パネルが開いてから寄る |
| 41〜45 秒の無音 | 無音ビートを廃止（冒頭以外は全ビートにナレーション）|
| エージェント選択は喋りながら寄る | 静止画に押し込みのカメラ移動を付けた（1.71x）|

## 冒頭の時刻（ビート 1、6.7 秒・ナレーション無し）

| 時刻 | 何が起きるか |
|---|---|
| 0〜2.3s | 6 セルが全部動いている（俯瞰）|
| **2.3s** | **上段真ん中が amber に変わる。ここでチャイム**（実測 -18dB / BGM は -35dB）|
| 2.6〜4.0s | そのセルへ押し込み（1.9x）|
| 〜6.0s | 寄ったまま回答 → 作業中に戻る |

ビート 2 はこの続きを**同じアークから切り出した**もので、引きながらナレーションが始まる。

## 撮影で分かったこと（rig 側の学び・追加分）

- **新しいディレクトリの初回メッセージは `Yes, I trust this folder` に吸われる。** 再送ガードも
  ダイアログの中に入るだけで、セルはダイアログを表示したまま撮影に写る（v5 の 9 セルで発生）。
  **起動直後に全セルへ Enter を送って信頼を確定**してからプロンプトを出す
- **締めのサマリ（`appendSystemPrompt`）は日本語混入の経路**。repo の CLAUDE.md に英語ルールを
  書いても 9 セル中 1 つは日本語になった。デモ repo で `appendSystemPrompt: false` にして塞ぐ
- **`--cwd` を渡さないとワークスペースが「起動したディレクトリ」になる** — その色設定が未起動セルの
  背景に出て、実パスも載る。`capture-server.sh` に `--cwd /tmp/mt-demo` を追記済み
- **撮影中に実 MulmoTerminal を触ると、復元後も実設定にデモのプリセットが残る**（メモリ経由の
  書き戻し）。今回実際に発生し、バックアップ `config.json.real-*` から復旧した
