# mulmoterminal-60s.json — hn md 構成のドラフト

launch-show-hn.md §4 の構成でのドラフト（90秒版 = capture-guide §6-2 構成との**比較検討用**）。
§4 の指定: 冒頭10秒で2拍（①1つが amber になる ②クリックして拡大・回答、他は走り続ける）を固定、
抽象語で始めない、実装の説明は30秒以降。中盤以降は §3 のキーメッセージ順
（状態 → 多数と一つの両立 → エージェント非依存 → 消えない → 離れられる）。

## 90秒版との関係

- 素材は 90秒版と共有（`mulmoterminal-90s-assets/` を参照。60s 専用は `open-grid.mp4` と
  `agent-tabs-still.png` の2つで、同ディレクトリに置いた）
- **ナレーションは全文ドラフト** — 60秒版には確定コピーが存在しない（§6-2 の確定英文は90秒版のもの）。
  採用が決まったらコピーの確定レビューが必要
